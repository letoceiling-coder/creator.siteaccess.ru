# AGENTS.md

Инженерные правила AI Creative Studio. Этот файл действует на весь репозиторий. Узкие инструкции лежат в Skills (`.cursor/skills/*/SKILL.md`) и в правилах (`.cursor/rules/*.mdc`).

## Граница фазы

Сейчас собрана основа, не продукт. Без отдельного задания не делать главную страницу сервиса, каталоги фото и видео, личный кабинет, авторизацию, backend, API генерации, оплату и загрузку файлов на сервер. Не вызывать модели и не генерировать изображения.

## Стек

React 19, TypeScript 7 (strict), Vite 8, Tailwind CSS 4, Motion, Lucide, React Router 7, Zod 4, React Hook Form. Тесты: Vitest, Testing Library, Playwright, axe-core. Формат: Prettier. Линт: Oxlint. ESLint не ставить — он дублирует Oxlint и не является линтером этого шаблона Vite.

Node для проверки: 24.16. Менеджер пакетов: npm. В `engines` указано `>=22.12.0`.

## Как устроен код

- `src/app` — провайдеры, тема, маршруты.
- `src/pages` — оболочка и стенд компонентов.
- `src/features/platform` — определение браузера, Telegram и MAX и адаптеры. UI не читает глобальные объекты хоста сам.
- `src/components/ui` — кнопки, поля, карточки, переключатель, диалог, тосты, спиннер, скелетон.
- `src/components/layout` — каркас с шапкой, safe area и нижней зоной мини-приложения.
- `src/shared` — `cn` и контракт формы.
- `src/hooks` — media query и visual viewport.
- `src/config` — палитра для тестов, движение, брейкпоинты.
- `src/styles/global.css` — токены.

Импорты из `src` идут через `@/` и заканчиваются расширением `.ts` или `.tsx`. Типы — через `import type`. `enum` нельзя: включён `erasableSyntaxOnly`.

## Маршруты

Одно приложение. `/` — браузер, `/telegram` — Telegram, `/max` — MAX, `/dev/foundation` — стенд. Реальный `window.Telegram.WebApp` или `window.WebApp` важнее пути. Путь без SDK только показывает зону предпросмотра.

## Интерфейс

Цвета, тип, радиус и тень брать из токенов. Тема — атрибут `data-theme` на `<html>`. Компонент не хранит собственную палитру. Интерактив не ниже 44px. Базовая раскладка обязана жить на 320px. Анимации — `transform` и `opacity`, длительности 140 / 220 / 360 мс, с `prefers-reduced-motion`.

## Проверка

Не объявлять задачу готовой по одной сборке. Для кода: `npm run typecheck`, `npm run lint`, `npm run test`. Для сборки модулей: `npm run build`. Для экрана: `npm run test:e2e` и просмотр desktop, tablet, mobile, маршрутов `/telegram` и `/max`. В отчёт попадают только запущенные команды.

## Зависимости

Новый пакет — когда в репозитории нет средства решить задачу. Сначала сверить совместимость. Не ставить вторую библиотеку анимации, второй линтер, UI-кит и SDK мессенджеров, пока интеграция не запрошена.
