# web-performance

## Назначение

Интерфейс стабилен при загрузке и остаётся отзывчивым на телефоне. Главный враг здесь — скачок высоты и лишний вес, а не микрооптимизация рендера.

## Когда применять

Новая зависимость, картинка, шрифт, маршрут, эффект, список, анимация, сторонний скрипт.

## Область

Сборка Vite. Сейчас в начальный граф входят оболочка и UI. Стенд грузится отдельно через `lazy`. Шрифты Syne Variable и Outfit Variable подключены через `@fontsource-variable` в `src/main.tsx`. Фотографии стенда лежат в `src/assets/playground` и занимают заранее заданный `aspect-*`.

## Инструкции

1. Перед `npm install` назвать, какую существующую возможность пакет заменяет и почему своей функции мало. Проверить peer dependencies с React 19 и TypeScript 7.
2. Тяжёлый экран подключать через `lazy` внутри уже смонтированного `AppFrame`, чтобы каркас не исчезал. Запасной блок имеет минимальную высоту (`min-h-48` или скелетон нужного размера).
3. Картинке задавать ширину и высоту или `aspect-*` до `onload`. Не вставлять изображение без резерва.
4. Шрифт не подключать с внешнего CSS без нужды. Если добавляется начертание, оставить `font-display` и запасной стек в `--font-sans` / `--font-display`, чтобы текст был читаем до загрузки файла.
5. Не создавать состояние, которое меняется на каждый кадр скролла. Подписка на viewport — через `useSyncExternalStore`, и снимок должен быть стабильным примитивом, иначе React зациклится.
6. Эффект с таймером очищать на размонтировании, как таймеры тостов.
7. Сторонний скрипт хоста не вставлять в `index.html` заранее: он нужен только внутри своего WebView и только после решения об интеграции.
8. После крупной зависимости смотреть `npm run build` и размер нового чанка. Если чанк стенда или оболочки вырос без новой задачи, убрать причину.

## Правила

- Один пакет на задачу. Motion уже закрывает анимацию, Zod — схемы, React Hook Form — формы, Oxlint — линт.
- Список не рендерить целиком, если его ещё нет. Бесконечных демо-списков не добавлять.
- Тени и размытия не навешивать на большие прокручиваемые области.
- `StrictMode` не отключать, чтобы спрятать двойной вызов эффекта. Эффект должен это переживать.

## Запрещено

- Скрипт аналитики, виджет и UI-кит «на будущее».
- Картинка неизвестной высоты над текстом.
- `useEffect` + `setState` на каждый `scroll`, если задачу решает CSS.
- Импорт всей библиотеки иконок другим способом, чем именованный импорт `lucide-react`.

## Критерии качества

- При загрузке стенда блоки не прыгают.
- Повторный рендер не завязан на новый объект в `getSnapshot`.
- Производственная сборка проходит.

## Пример

Медиаслот карточки занимает место сразу:

```tsx
<div className="bg-canvas grid aspect-video place-items-center">{mediaLabel}</div>
```

## Чек-лист

- [ ] Зависимость обоснована и не дублирует уже установленную.
- [ ] Тяжёлый экран отделён и имеет резерв высоты на время загрузки.
- [ ] Медиа и скелетоны не меняют высоту соседей после появления.
- [ ] Подписки снимаются.
- [ ] `npm run build` выполнен, если менялся граф модулей или зависимости.
