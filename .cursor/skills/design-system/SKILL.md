# design-system

## Назначение

Любой компонент выглядит частью одной системы. Смена темы — правка переменных в `src/styles/global.css`, не обход десятков файлов.

## Когда применять

Новый контрол, новое состояние, правка цвета, отступа, радиуса, тени, шрифта, темы.

## Область

Источник истины для CSS — `src/styles/global.css`. Зеркало палитры для проверки контраста — `src/config/palette.ts`. Шкала движения — `src/config/motion.ts`. Готовые контролы — `src/components/ui`.

Роли цвета:

- `canvas` / `canvas-raised` — фон страницы и приподнятая поверхность.
- `ink` / `ink-muted` — основной и вторичный текст.
- `line` — тихий разделитель. `line-strong` — граница поля, карточки и трека: у неё контраст к поверхности не ниже 3:1.
- `accent` — текст и фокус. `accent-fill` + `accent-ink` — заливка кнопки. В тёмной теме это разные значения, не один цвет.
- `danger` и `success` устроены так же: цвет текста меняется с темой, заливка кнопки остаётся тёмной, чернила на заливке светлые.

Отступы — шкала Tailwind (4px). Не заводить вторую. Радиусы: `rounded-sm` 6px, `rounded-md` 12px, `rounded-lg` 20px. Тени: `shadow-raised`, `shadow-overlay`. Тип: `text-caption`, `text-body`, `text-title`, `text-display`. Контейнер страницы — `max-w-6xl`.

## Инструкции

1. Новый цвет добавлять парой в `:root` и `[data-theme='dark']`, затем прокинуть в `@theme inline` как `--color-*`.
2. Тот же hex добавить в `palette.ts`. Иначе тест синхронизации упадёт. Это сделано намеренно.
3. Текст на фоне проверять на 4.5:1, границу поля на 3:1. Тест `tokens.test.ts` уже считает пары из `textPairs` и `controlPairs`. Новую текстовую пару туда добавить.
4. Кнопки брать из `Button` и `buttonClasses`. Поля — `TextField`. Не собирать вторую кнопку классами в странице, если хватает варианта.
5. Состояния контрола: default, hover, focus-visible, disabled, loading, error. Disabled — это `disabled:opacity-50`, не новый серый из головы.
6. Карточка с медиа обязана резервировать прямоугольник до картинки.
7. Модалка и тост используют `canvas-overlay` и тень overlay. Стекло на фото — утилита `surface-glass`, текст остаётся на плотной подложке.

## Правила

- Компонент потребляет утилиты (`bg-canvas`, `text-danger`), не сырые `var(--danger)`, кроме глобального CSS.
- Тема переключается атрибутом `data-theme` на `<html>`. Скрипт в `index.html` ставит его до отрисовки.
- Имена токенов описывают роль, не оттенок. Не создавать `--copper`.

## Запрещено

- Цвет, которого нет в `@theme`.
- Копия кнопки или поля с другими радиусами.
- Тёмная тема через отдельные классы `dark:bg-black`, пока переменная уже меняется сама.
- Палитра «только для этого экрана».

## Критерии качества

- Переключение темы не оставляет светлый текст на светлом фоне.
- Новый контрол на стенде стоит рядом со старыми и не спорит с ними.
- `npm test` держит контраст и синхронность палитры.

## Пример

```tsx
<button className={buttonClasses('secondary')} type="button">
  Вторичная
</button>
```

Заливка primary — `bg-accent-fill text-accent-ink`, не `bg-accent`: в тёмной теме `accent` светлый и не годится как фон кнопки.
