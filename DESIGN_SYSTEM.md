# Дизайн-система Helios

Источник токенов — `src/styles/global.css`. Палитра продублирована в `src/config/palette.ts`, чтобы тест мог проверить контраст и поймать рассинхрон. Менять цвет нужно в обоих местах.

Тема включается атрибутом `data-theme="light"` или `data-theme="dark"` на `<html>`. Компоненты не ветвятся классами `dark:`.

Светлая и тёмная темы — две сцены. Тёмная: графитовая градация, тёплые чернила, светящийся вольфрам. Светлая: холодный стол просмотра, тёплый лист карточки, глубокая латунь кнопки. Это не инверсия одной палитры.

## Цвет

Роли, не оттенки. Акцент один: вольфрам. Им отмечают главное действие, фокус, выбранную границу и ход. Статусы — отдельные.

| Токен                                    | Задача                                     |
| ---------------------------------------- | ------------------------------------------ |
| `canvas`                                 | Сцена страницы                             |
| `canvas-sunken`                          | Колодец поля и трека                       |
| `canvas-raised`                          | Лист карточки                              |
| `canvas-overlay`                         | Пластина диалога, меню, тоста              |
| `ink`, `ink-muted`                       | Основной и вторичный текст                 |
| `line`                                   | Тихий разделитель                          |
| `line-strong`                            | Граница поля и вторичной кнопки            |
| `accent`                                 | Текст акцента и кольцо фокуса              |
| `accent-fill`, `accent-ink`              | Заливка основной кнопки и текст на ней     |
| `danger`, `danger-fill`, `danger-ink`    | Текст сбоя и опасная кнопка                |
| `success`, `success-fill`, `success-ink` | Текст успеха и заливка                     |
| `wash`                                   | Тихий фон наведения, `color-mix` от чернил |

`accent` в тёмной теме светлый. Заливка кнопки — `accent-fill`, иначе светлый текст окажется на светлом фоне.

Текст на своём фоне — не ниже 4.5:1. `line-strong` к поверхностям поля — не ниже 3:1. Пары перечислены в `textPairs` и `controlPairs`.

## Типографика

| Утилита                          | Роль                                                     |
| -------------------------------- | -------------------------------------------------------- |
| `font-display`, `text-display`   | Крупный заголовок. Syne, текучий размер, плотный трекинг |
| `font-display`, `text-title`     | Заголовок секции и карточки                              |
| `font-sans`, `text-body`         | Интерфейс. Outfit                                        |
| `text-caption`, `tracking-label` | Подпись группы                                           |

Запасной стек — Segoe UI. Файлы подключаются в `src/main.tsx` через `@fontsource-variable`, с `font-display: swap` из пакета. Браузер скачивает только нужные подмножества по `unicode-range`.

`cn` знает размеры `text-caption`, `text-body`, `text-title` и `text-display` и отделяет их от цветовых классов.

## Отступы, радиус, тень

Отступы — шкала Tailwind: `1` = 4px. Шаг секций стенда — `gap-16`, внутри группы — `gap-4` и `gap-6`.

Радиусы: `rounded-sm` 8px, `rounded-md` 12px, `rounded-lg` 20px.

Тени: `shadow-raised` у листа, `shadow-overlay` у тоста, меню и диалога.

Оболочка стенда — `max-w-[88rem]`. Остальные маршруты — `max-w-6xl`.

## Брейкпоинты

База — 320px. Затем `sm` 640, `md` 768, `lg` 1024, `xl` 1280, `2xl` 1536. В JS те же пороги в `src/config/breakpoints.ts`. Playwright смотрит 320, 360, 390, 430, 768, 1024, 1280 и 1536.

## Движение

140ms — нажатие, меню, переключатель. 220ms — появление тоста и диалога. 360ms — длинное появление. Кривые standard, enter и exit. В React — `src/config/motion.ts`: `rise` 12px, `press` 0.98.

Движутся `opacity` и `transform`. При `prefers-reduced-motion: reduce` глобальный CSS обнуляет длительности, а Motion-компоненты ставят duration в 0.
