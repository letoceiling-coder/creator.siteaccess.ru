# Skills

Проектные Skills лежат в `.cursor/skills/<имя>/SKILL.md`. Cursor подхватывает этот каталог сам. Формат — Agent Skills: папка, внутри `SKILL.md`, во frontmatter обязательны `name` и `description`. `name` совпадает с именем папки, только строчные латинские буквы, цифры и дефисы. `description` говорит, что делает инструкция и когда её брать в работу. Поле `paths` ограничивает skill файлами, которые агент уже трогает.

Короткие всегда включённые ограничения лежат отдельно:

- `AGENTS.md` — архитектура и запреты фазы;
- `.cursor/rules/*.mdc` — правила Cursor. Файл без frontmatter в `.cursor/rules` не применяется.

Skill не дублируют в правило целиком. Правило напоминает границу, skill даёт шаги.

## Набор

| Skill                | Когда                                       |
| -------------------- | ------------------------------------------- |
| `frontend-design`    | Внешний вид, иерархия, плотность            |
| `responsive-design`  | Ширины от 320px, сетки, safe area           |
| `motion-design`      | Переходы, hover, модалки, загрузка          |
| `react-architecture` | Куда класть код и как делить состояние      |
| `design-system`      | Токены и состояния контролов                |
| `mobile-app-ux`      | Telegram, MAX, касания, клавиатура          |
| `web-performance`    | Вес, шрифты, CLS, зависимости               |
| `accessibility`      | Клавиатура, имена, контраст, WCAG           |
| `frontend-testing`   | Команды проверки и виды тестов              |
| `visual-qa`          | Просмотр экрана, без выдуманного результата |

## Как добавить skill

1. Создать `.cursor/skills/<имя>/SKILL.md`.
2. Заполнить frontmatter. `name` равен имени папки. Описание короче 1024 символов и содержит ситуацию, в которой skill нужен.
3. В теле оставить рабочие шаги: когда применять, как делать, что запрещено, критерий готовности, короткий пример, чек-лист. Не писать манифест без действий.
4. Если инструкция нужна только рядом с определёнными файлами, добавить `paths`.
5. Дописать строку в таблицу этого файла.
6. Постоянный запрет на каждую сессию класть в `.cursor/rules` или в `AGENTS.md`, а не в skill. Skill подключается по задаче, а не всегда.

Проверка формата: открыть новый чат агента и убедиться, что skill виден по имени. Неисправный frontmatter Cursor показывает предупреждением и не выбирает сам.
