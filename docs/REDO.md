# Переделка результата

ИИ может ошибаться, поэтому у каждой готовой задачи есть **одна бесплатная переделка**. Она доступна 48 часов, пока результат не скачан. Код: `server/api/redo.mjs` и `src/pages/studio/redo-panel.tsx`.

## Как устроено

- **Журнал генерации.** Воркер записывает его в `jobs.trace`:
  - промпт каждого кадра и сцены;
  - сиды всех попыток;
  - оценки проверки: сходство лица с фото по SFace, лицо целиком в кадре, доля кадров видео с тем же человеком.
- **Фото пользователя** хранятся 48 часов после готовности задачи — для переделки. После скачивания или окончания окна они удаляются.
- **Скачивание закрывает переделку.** Ссылки «Скачать» отмечают задачу (`POST /api/jobs/:id/downloaded`).
- **Запрос пользователя** (`POST /api/jobs/:id/redo`):
  - причины (лицо, обрезано, руки, образ, сюжет, качество, движение, звук);
  - для фото — какие кадры переделать;
  - комментарий; он проходит модерацию.
- **Рецензент** — недорогая платная модель OpenRouter (по умолчанию `deepseek/deepseek-v4-flash`, ≈ $0.0005 за переделку; меняется в «Интеграциях»). Если она недоступна — бесплатные модели, Ollama, затем правила.
  - Получает журнал и жалобу, **без изображений** — лица пользователей во внешний сервис не уходят.
  - Возвращает: диагноз для пользователя, заметку для шаблона, добавки к промпту и негативу, строгий режим сходства.
  - Правки проходят тот же фильтр, что и пользовательский текст.
- **Новая задача** создаётся с `options.fixes` и бесплатно:
  - новые сиды;
  - выбранные кадры;
  - в строгом режиме — порог сходства 0.6 и 4 попытки.
  - Переделку саму переделать нельзя.
- **Админка → «Качество»:** причины, сюжеты, которые переделывают чаще, диагнозы и заметки рецензента — материал для улучшения шаблонов.
