# Дорожная карта

Видео заложено в данные, каталог и статусы сразу. Считать его на карте в первой поставке нельзя: одна общая RTX 4090 и отсутствие подтверждённого замка лица между сценами.

Цены ни в один этап не ставятся, пока нет замера времени и памяти на выбранном графе.

## MVP

Цель: один человек проходит фотосессию до скачивания и видит её в истории.

Входит:

1. Регистрация и вход одним утверждённым способом.
2. Каталог и карточка фотосессии на Helios, телефон в приоритете.
3. Мастер: фото, короткий образ, подтверждение.
4. Задача со статусами и повторным открытием.
5. Один граф Qwen-Image-Edit Fast через новый брокер, строго один прогон на карту.
6. Просмотр, скачивание, история, удаление результата.
7. Пустой кабинет с путём в каталог.

Не входит: видео, оживление, коллаж, кредиты, избранное, библиотека всех фото, обучение лица, свободный промпт, параллельные задачи, остановка уже идущего ComfyUI.

Зависимости до кода MVP:

- Решение владельца хоста, как брокер узнаёт, что карта занята чужим сервисом.
- Один измеренный прогон Edit Fast на 1–3 референсах: время, память, пригодность сходства.
- Выбор способа входа.
- Тексты и обложки хотя бы нескольких сценариев. Обложки не генерируются этим проектом вслепую на боевой карте.

## Version 1.1

- Каталог видео с раскадровкой, без запуска или с одним коротким роликом из одного клипа Wan 5 секунд, если замер фото уже стабилен.
- Оживление одного готового снимка как отдельный тип, если для него выбран подтверждённый граф.
- Избранное, уведомление внутри кабинета, настройки.
- Библиотека загруженных фото.

Зависимость: видео не начинается, пока фото MVP доходит до `completed` без ручной чистки карты.

## Version 1.2

- Многосценный сценарий как последовательность клипов, по одному на GPU, со склейкой ffmpeg.
- Коллаж из готовых кадров на CPU.
- Проекты.
- Кредиты, если к этому моменту есть таблица реальной стоимости: шаги, разрешение, апскейл, число клипов. Не цена за секунду ролика.

## Version 2.0

- Несколько исполнителей GPU за тем же брокером.
- Связка одного человека между браузером, Telegram и MAX.
- Более сильное сохранение лица, только если на сервере появятся подтверждённые веса. Пока их нет, версия 2.0 не имеет права обещать LoRA или IP-Adapter.
- Остановка идущего прогона, если появится подтверждённый способ.

## Порядок

```text
замер Edit Fast и правило занятости GPU
  → MVP фото
    → 1.1 короткий ролик или оживление
      → 1.2 много сцен и тариф
        → 2.0 несколько карт и более сильное сходство
```

Поставить 1.2 раньше стабильного MVP нельзя: многосценный ролик умножает очередь и риск испортить карту соседним сервисам.
