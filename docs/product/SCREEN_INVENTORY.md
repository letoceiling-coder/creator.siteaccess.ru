# Реестр экранов и каркасы

Каркасы показывают порядок блоков и действия. Они не заменяют экран Helios и в сборку не входят. Пропорции фото фиксируются заранее, чтобы лента не прыгала.

Состояния, общие для списков: `loading` скелетом, `ready`, `empty`, `error` с повтором. У задачи дополнительно все статусы генерации.

## Реестр

| Экран | Ключевые состояния | Фаза |
| --- | --- | --- |
| Главная | loading, ready, error каталога | 1.1 |
| Каталог фото | loading, ready, empty filter, error | MVP |
| Карточка фото | loading, ready, unpublished 404 | MVP |
| Каталог видео | ready, coming soon на кнопке | 1.1 |
| Карточка видео | ready, create disabled | 1.1 |
| Мастер фото | empty, invalid file, uploading, ready | MVP |
| Мастер образа | default, validation | MVP |
| Проверка | ready, submitting, 409 | MVP |
| Задача | все статусы, offline | MVP |
| Результат | completed, not found, deleting | MVP |
| Вход и регистрация | form, error, submitting | MVP |
| Обзор кабинета | empty, has job | MVP |
| История | empty, list, error | MVP |
| Остальной кабинет | empty | по дорожной карте |

## Главная, телефон

```text
┌──────────────────────────────┐
│ Studio                  тема │
├──────────────────────────────┤
│ Кадры, где герой — вы        │
│ [ Выбрать фотосессию ]       │
│ Смотреть видеосценарии       │
│ ┌──────────────────────────┐ │
│ │        hero-кадр         │ │
│ └──────────────────────────┘ │
│ Как это устроено             │
│ 1 сценарий  2 фото  3 готово │
│ Популярные фотосессии  →     │
│ ┌────┐ ┌────┐ ┌────┐         │
│ │ 3:4│ │ 3:4│ │ 3:4│         │
│ └────┘ └────┘ └────┘         │
│ Видеосценарии                │
│ Вопросы                      │
│ Футер                        │
├──────────────────────────────┤
│ Главная Фото Видео Кабинет   │
└──────────────────────────────┘
```

На широком экране нижней панели нет, hero стоит в два столбца, футер остаётся.

## Каталог фотосессий

```text
┌──────────────────────────────┐
│ Фотосессии                   │
│ [ Поиск ................. ]  │
│ Дубай  Море  Fashion  →      │
│ ┌────────────┐               │
│ │   обложка  │               │
│ │   3:4      │               │
│ │ Название   │               │
│ │ 8 кадров   │               │
│ └────────────┘               │
│ ┌────────────┐               │
│ │   следующий│               │
│ └────────────┘               │
└──────────────────────────────┘
```

С 768 px карточки встают в две колонки. Поиск фильтрует уже загруженную страницу и догружает следующую порцию.

## Карточка фотосессии

```text
┌──────────────────────────────┐
│ ┌──────────────────────────┐ │
│ │         обложка          │ │
│ └──────────────────────────┘ │
│ ┌────┐┌────┐┌────┐┌────┐    │
│ │кадр││поза││ракурс││ещё│   │
│ └────┘└────┘└────┘└────┘    │
│ Название                     │
│ Образ и одежда               │
│ Нужны 1–3 фото лица          │
│ На выходе N кадров           │
│ Оценка очереди               │
│ [ Создать ]                  │
└──────────────────────────────┘
```

Галерея примеров прокручивается внутри полосы и не растягивает страницу.

## Каталог видео

Та же колонна, на карточке постер и длительность. Бейдж «Скоро», если создание выключено.

## Карточка видео

```text
┌──────────────────────────────┐
│ ┌──────────────────────────┐ │
│ │      пример ролика       │ │
│ └──────────────────────────┘ │
│ Погоня в Дубае               │
│ Сцены                        │
│ 1 Салон                      │
│ 2 Лицо                       │
│ 3 Машина и улица             │
│ 4 Бок / сзади / сверху       │
│ 5 Финал                      │
│ Нужны фото лица анфас       │
│ [ Создание откроется позже ] │
└──────────────────────────────┘
```

Когда запуск включат, нижняя кнопка станет «Создать» и поведёт в тот же мастер.

## Загрузка фотографий

```text
┌──────────────────────────────┐
│ Фото · Образ · Проверка      │
│ ┌──────────────────────────┐ │
│ │  Выбрать с телефона      │ │
│ └──────────────────────────┘ │
│ ┌────┐ ┌────┐ ┌────┐         │
│ │    │ │    │ │ +  │         │
│ │ ✕  │ │ ✕  │ │    │         │
│ └────┘ └────┘ └────┘         │
│ Лицо видно, без сильного     │
│ фильтра и без перекрытия     │
│ [ Дальше ]                   │
└──────────────────────────────┘
```

Непринятый файл остаётся в списке ошибок над сеткой и в сетку не попадает. «Дальше» выключено, пока нет хотя бы одного годного снимка.

## Образ

```text
┌──────────────────────────────┐
│ Фото · Образ · Проверка      │
│ Одежда                       │
│ ( ) как в сценарии           │
│ ( ) светлый костюм           │
│ Время суток                  │
│ [ День | Закат | Ночь ]      │
│ Пожелание, необязательно     │
│ [ ........................ ] │
│ [ Дальше ]                   │
└──────────────────────────────┘
```

Набор строк другой у другого сценария. Для погони вместо одежды — короткий список машин сценария.

## Подтверждение

```text
┌──────────────────────────────┐
│ Проверьте задачу             │
│ Сценарий: Северный берег     │
│ Фото:  ▢ ▢                   │
│ Образ: день, как в сценарии  │
│ Кадров: 8                    │
│ Очередь: оценка появится     │
│ Стоимость: после утверждения │
│ [ Подтвердить создание ]     │
│ Вернуться                    │
└──────────────────────────────┘
```

Пока тариф не утверждён, строки стоимости нет вообще, а не нулевая цена.

## Генерация

```text
┌──────────────────────────────┐
│ Собираем кадры               │
│ ████████░░░░  очередь        │
│ Можно закрыть страницу.      │
│ Работа сохранится в кабинете.│
│ [ Отменить ]                 │
└──────────────────────────────┘
```

Полоса отражает статус, не процент карты. «Отменить» активно в `pending` и `queued`.

## Результат

```text
┌──────────────────────────────┐
│ Северный берег               │
│ ┌────────────┐┌────────────┐ │
│ │   кадр 1   ││   кадр 2   │ │
│ └────────────┘└────────────┘ │
│ [ Скачать все ]              │
│ Собрать снова                │
│ Удалить                      │
└──────────────────────────────┘
```

Удаление открывает диалог Helios. «Собрать снова» не запускает генерацию.

## Кабинет

```text
┌──────────────────────────────┐
│ Кабинет                      │
│ Пока нет готовых работ.      │
│ [ Выбрать фотосессию ]       │
│ История                      │
│ Профиль                      │
└──────────────────────────────┘
```

Когда работа есть, наверху её карточка: название, статус, дата. На широком экране слева список разделов, справа содержимое. Нижняя панель телефона остаётся.
