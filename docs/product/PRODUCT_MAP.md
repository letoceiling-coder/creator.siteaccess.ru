## Каталог фотосессий

Категории расширяемые, код категории стабильный, название можно сменить без миграции адресов.

| Код | Название |
| --- | --- |
| `travel` | Путешествия |
| `dubai` | Дубай |
| `egypt` | Египет |
| `paris` | Париж |
| `turkey` | Турция |
| `maldives` | Мальдивы |
| `mountains` | Горы |
| `sea` | Море |
| `africa` | Африка |
| `extreme` | Экстремальные приключения |
| `luxury` | Luxury Lifestyle |
| `fashion` | Fashion |
| `business` | Деловой стиль |
| `sport` | Спорт |
| `cars` | Автомобили |
| `romance` | Романтические образы |
| `family` | Семейные фотосессии |
| `season` | Сезонные образы |
| `holiday` | Праздничные фотосессии |

У карточки каталога есть название, категория, обложка, галерея примеров, описание, визуальный стиль, число итоговых кадров, формат, требования к исходникам, одежда, как сохраняется внешность, оценка времени и стоимость в кредитах, если тариф утверждён. Пока тариф не утверждён, цена на карточке не показывается: стоит пометка, что стоимость появится до запуска.

Примеры в галерее — заранее подготовленные иллюстрации сценария, не кадры конкретного пользователя.

## Каталог видео

| Код | Название |
| --- | --- |
| `action` | Экшен |
| `chase` | Погони |
| `cars` | Автомобили |
| `travel` | Путешествия |
| `adventure` | Приключения |
| `fantasy` | Фантастика |
| `crime` | Криминальное кино |
| `thriller` | Боевики |
| `romance` | Романтика |
| `luxury` | Luxury Lifestyle |
| `sport` | Спорт |
| `music` | Музыкальные клипы |
| `humor` | Юмор |
| `holiday` | Праздничные сюжеты |

Категория `crime` — вымышленный кинематографический жанр. Запуск таких сценариев ждёт отдельного решения по содержанию: см. `OPEN_QUESTIONS.md`.

У сценария есть обложка, пример ролика, описание сюжета, длительность, число сцен, требования к фото, как персонализируется героя, ожидаемое качество и стоимость после утверждения тарифа.

Четыре опорных сюжета, все как контент каталога, не как готовые графы сервера:

1. Погоня в Дубае. Герой за рулём красной Ferrari, преследование, салон, лицо, улицы, камера сбоку, сзади и сверху, манёвры, финал.
2. Голливудский герой. Короткий эффектный ролик, герой в центре действия.
3. Роскошный отдых. Яхта, бассейн, отель или остров.
4. Экстремальное приключение. Горы, пустыня, непривычные локации.

Раскадровка каждого сюжета хранится как список `ScenarioScene`. Технический промпт кадра в интерфейс не попадает.

## Навигация

Телефон, нижняя панель, четыре пункта: Главная, Фото, Видео, Кабинет. Создание начинается с карточки сценария, отдельной пятой кнопки нет: на 320 px четыре цели по 44 px уже плотные. В мини-приложении панель садится в уже зарезервированную нижнюю зону каркаса.

Широкий экран: шапка со ссылками Фото, Видео, Кабинет и переключателем темы. Каталог — сетка. Карточка сценария — обложка слева, текст и действие справа. Кабинет — боковой список разделов и содержимое.

Футер только у главной и каталогов в браузере. В мини-приложении футера нет.
