# Telegram и MAX

Одна сборка. Платформу выбирает уже написанный `readPlatformSnapshot`: живой `window.Telegram.WebApp` важнее пути, затем `window.WebApp` с признаками MAX, иначе путь `/telegram` или `/max` остаётся предпросмотром без SDK. Компоненты хост сами не читают.

SDK в этой фазе не подключаются. `signalReady`, `close` и `bindBack` уже есть и ничего не делают, пока объекта хоста нет.

## Адреса

| Платформа | Корень | Пример будущего каталога |
| --- | --- | --- |
| Браузер | `/` | `/photos` |
| Telegram | `/telegram` | `/telegram/photos` |
| MAX | `/max` | `/max/photos` |

`homePath` адаптера уже указывает на `/`, `/telegram` или `/max`. Новые ссылки строятся от него, а не от жёсткого `/photos`, иначе мини-приложение выпадет в браузерный корень.

`/dev/foundation` по-прежнему общий.

## Вход

Клиент может передать `initData` только на `POST /api/v1/auth/telegram` или `POST /api/v1/auth/max`. Сервер проверяет подпись и срок. Непроверенная строка сессию не создаёт. Алгоритм подписи MAX — `UNKNOWN`.

Один человек может иметь и парольный вход браузера, и вход мини-приложения, когда появится связка учётных записей. В MVP достаточно одного способа, он ещё не выбран.

## Вёрстка

Safe area: у Telegram адаптер читает `contentSafeAreaInset`, затем `safeAreaInset`. У MAX до подключения SDK поля берутся из CSS `env(safe-area-inset-*)`, высота viewport — из окна. Каркас уже резервирует низ `4.5rem + env(safe-area-inset-bottom)`, когда платформа просит нижнюю зону.

Нижняя навигация продукта занимает эту зону, вторая панель снизу не добавляется. Шапка учитывает верхний inset, это уже делает каркас.

Системная кнопка назад: `adapter.bindBack` закрывает шаг мастера или просмотр кадра. Если шага назад нет, обработчик не перехватывает кнопку и даёт хосту закрыть мини-приложение. В браузере работает обычная история Router.

## WebView

- Файлы выбираются через `<input type="file" accept="image/*">`. Drag-and-drop только в браузере.
- Скачивание в браузере — обычная загрузка приватного URL. У MAX в типе хоста есть `downloadFile`, но вызов появится только вместе с SDK и после проверки, что URL доступен серверу хоста. До этого кнопка «Скачать» не обещает системный загрузчик.
- Внешняя ссылка открывается действием хоста, когда SDK будет подключён. До этого внешние ссылки в мини-приложении не ставятся: юридические тексты остаются внутри маршрута.
- Клавиатура не должна прятать кнопку подтверждения. Для этого уже есть учёт visual viewport на оболочке; мастер использует тот же приём.
- Пока задача в очереди, уход из WebView её не отменяет. Возврат открывает `/jobs/:jobId` заново.

## Предпросмотр без SDK

Пути `/telegram` и `/max` в обычном браузере остаются витриной платформы: `sdkReady` ложен, нижняя зона и кнопка закрытия видны как сейчас на оболочке. Это нужно разработке и не считается боевым входом.
