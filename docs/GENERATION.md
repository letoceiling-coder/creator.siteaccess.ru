## Фабрика контента (`server/factory`)

Набор скриптов Node, работающих через HTTP API ComfyUI. Состояние хранится в `state.json`, остановка и перезапуск безопасны (готовое пропускается).

| Файл | Назначение |
| --- | --- |
| `comfy.mjs` | Клиент ComfyUI и рабочие процессы: `qwenImageWorkflow`, `qwenEditWorkflow`, `wanVideoWorkflow`, `aceMusicWorkflow` |
| `locations.mjs` + `photos.mjs` | 30 локаций × 5 планов = 150 фото, WebP 1104 px и превью 420 px |
| `music.mjs` | 30 инструментальных треков по ТЗ из каталога, нормализация −14 LUFS, MP3 160 кбит/с |
| `videos.mjs` | 30 демо-роликов: кадр → видео 5 с → музыка → mp4 (h264+aac) + постер |
| `video-templates.json` | Общие данные 30 шаблонов, их же читает сайт |

Развёртывание: каталог `/opt/creator-factory`, запуск как transient-юниты `creator-factory-photos|music|video` (`systemd-run`, `Nice=10`). Результаты: `/var/www/creator-media/{photos,music,video}`, раздаются сайтом как `/media/…` (блок `location /media/` в `/etc/nginx/sites-enabled/creator.siteaccess.ru`, резервная копия конфига `/root/creator.siteaccess.ru.conf.bak-20261117`).

Команды на сервере:

```bash
cd /opt/creator-factory
node photos.mjs status     # или music.mjs, videos.mjs
node videos.mjs run --only coast-run   # пересоздать один ролик
node videos.mjs mux        # заново подложить музыку под готовые ролики
```

Сайт читает `/media/photos/manifest.json` и `/media/video/manifest.json` (`src/features/media/use-media.ts`): каталог видео показывает настоящие постеры и плеер `ClipPlayer`, каталог фото — раздел «Локации». Если файлов нет, остаются раскадровка и подставные картинки.

## API задач пользователей (`server/api`) — работает с 2026-11-17

Без внешних зависимостей: `node:http`, `node:sqlite`, ffmpeg. Unit `creator-studio-api` (порт 127.0.0.1:3480), nginx проксирует `/api/`. Выкладка: `npm run deploy:api`, тесты без GPU: `npm run test:api`.

| Запрос | Что делает |
| --- | --- |
| `POST /api/jobs` | multipart: `kind` (photo/video), `target`, `outfit` 0–2, `time` day/dusk/night, `consent=yes`, `photos` 1–3. Ответ: `id`, `token`, место в очереди |
| `GET /api/jobs/:id` | статус, прогресс, результаты; `Authorization: Bearer <token>` |
| `POST /api/jobs/:id/cancel` | отмена в очереди или между шагами |
| `GET /api/health` | состояние очереди |

- Фото: 5 кадров через Qwen-Image-Edit 2511, у каждого плана своя поза и крупность. Видео: кадр с человеком → Wan 2.2 (5 с) → музыка шаблона.
- Задачи пользователей ставятся в начало очереди ComfyUI (`front`), фабрика их не задерживает. Один GPU — одна задача за раз.
- Проверки: тип файла по сигнатуре (JPEG/PNG/WebP), до 15 МБ, тело до 48 МБ, короткая сторона от 256 px. Перекодирование ffmpeg снимает EXIF и геометки.
- Свободного текста в промпте нет: только сценарий, одежда и время суток из списка.
- Лимиты: 2 активные задачи и 10 в сутки на клиента (хэш IP с солью, сам IP не хранится), очередь до 30.
- Исходники удаляются сразу после обработки (у нас и во входе ComfyUI), результаты — через 7 дней. `/media/jobs/` без листинга, `noindex`, адреса — случайные 128-битные id.
- Входа нет: доступ к задаче — по токену, он хранится в браузере (`localStorage`), кабинет показывает задачи этого браузера.

Замер 2026-11-17 при работающей фабрике: фотосессия 5 кадров — 3–4 минуты, видео — около 2 минут.

### Что ещё нужно для боевого запуска

1. Вход (Telegram/MAX initData, браузер) и перенос задач к аккаунту, лимиты и оплата.
2. Модерация входящих фото и результатов.
3. Договорённость об общем GPU с другими проектами сервера.
4. Качество на реальных фото пользователей не измерено: пробы на синтетических портретах. На крупных планах поза рук иногда повторяет исходное фото.

## Ограничения

- Музыка в роликах создана ИИ (ACE-Step). До публикации проверьте лицензию модели и условия коммерческого использования; либо заменить на лицензионные треки.
- Все люди на образцах — вымышленные, кадры помечены «создано ИИ».
- Ролик демонстрации — 5 секунд, а не длина шаблона (8–12 с). Длинные версии потребуют склейки нескольких клипов.
- Качество перенесённого лица на реальных фото пользователей не измерено: проба сделана на синтетическом портрете.
