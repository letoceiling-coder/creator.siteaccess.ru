# Публикации в каналы

Админка → «Публикации». Пост уходит через ботов студии: Telegram (@creator_st_bot) и MAX. Код — `server/api/channels.mjs`, экран — `src/pages/admin/admin-page.tsx` (`Publications`).

## Что можно отправить

- Текст с разметкой: `**жирный**`, `_курсив_`, `[текст](https://ссылка)`. В Telegram она превращается в HTML, в MAX уходит как markdown.
- До 10 фото и видео в одном посте; если файлов несколько, они уходят галереей. Порядок меняется стрелками.
- Необязательная кнопка-ссылка под постом (только `https://`, текст до 64 символов).
- Несколько каналов сразу. Результат и ссылка на пост показываются по каждому каналу; посты попадают в историю.

## Ограничения платформ (проверяются в форме и на сервере)

| | Telegram | MAX |
|---|---|---|
| Текст | 4096 символов | 4000 символов |
| Подпись к медиа | 1024 символа | — (текст и вложения в одном сообщении) |
| Вложений | галерея 2–10 | до 12 (включая клавиатуру) |
| Фото | 10 МБ | 50 МБ, до 7680×7680 |
| Видео | 50 МБ (стандартный Bot API) | 250 МБ |
| Частота | ~20 постов в минуту на канал | 2 сообщения в секунду, 30 запросов в секунду |

Общий предел запроса — 260 МБ (nginx: `location = /api/admin/posts`, 270m, таймаут 900 с).

Особенности:

- **Telegram.** Если текст длиннее 1024 символов, медиа отправляются без подписи, а текст идёт следующим сообщением. К альбому нельзя прикрепить кнопку, поэтому она тоже идёт отдельным сообщением.
- **MAX.** Файл загружается через `POST /uploads`, затем отправляется сообщение с токенами вложений. Пока видео обрабатывается, MAX отвечает `attachment.not.ready`; сервер повторяет отправку с растущей паузой.

## Каналы

- **Telegram.** Канал добавляется по `@имени` или ссылке t.me. Сервер проверяет, что это канал и что у бота есть право `can_post_messages`.
- **MAX.**
  - Список чатов бота в API MAX недоступен. Студия узнаёт ID канала из события `bot_added`: на вебхук бота подписаны `bot_added` и `bot_removed`.
  - Если канал не появился, уберите бота из администраторов канала и назначьте снова.
  - ID можно ввести и вручную (число, обычно отрицательное). Сервер проверит его через `GET /chats/{id}`.

Бот должен быть администратором канала с правом публикации.
